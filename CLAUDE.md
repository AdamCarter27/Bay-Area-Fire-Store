# Bay Area Fire Store — Demo Rebuild

## Stack
Next.js (App Router) + TypeScript + Tailwind CSS + React Context for cart state.
No real backend/payments for right now, using mock data in lib/data/products.ts.

## Goal
Build a demo to pitch the site owner on replacing their current Wix site.
Firefighter apparel/merch store: headwear, jackets, hoodies, tees, custom
embroidery/screen printing, department/brand collections (SFFD, SFPD, etc.)

## Folder structure
app/ - pages (home, shop, product/[slug], custom-order, cart, about)
components/ - layout/, product/, cart/, ui/
lib/data/ - mock product data, structured like future Shopify data
  (title, price, image, variants, category)
